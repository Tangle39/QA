计算机有多种存储设备，按照访问速度和作用可以分为：

- **寄存器（Register）** → 速度最快，CPU内部存储，容量极小。
- **高速缓存（Cache，L1/L2/L3）** → 速度快，存 CPU近期数据，提高访问速度。
- **主存（RAM）** → 计算机运行程序的主要工作区，容量比 Cache 大，速度比磁盘快。
- **辅存（外存，如 SSD/HDD）** → 速度最慢，但容量最大，存储长期数据。

**物理地址（Physical Address）** 是计算机内存的 **真实地址**，由 CPU 直接用于访问 RAM。

计算机的内存寻址方式可以分为：

1. **物理地址（Physical Address）**：
   - 直接指向 RAM 的某个存储单元。
   - 例如，物理地址 `0x100000` 可能表示 RAM 的某个位置。
   - 只有 **DMA、MMU（内存管理单元）和硬件** 直接使用物理地址。
2. **虚拟地址（Virtual Address）**：
   - 操作系统为进程提供的地址，程序看到的**并不是物理地址**。
   - 例如，一个程序访问 `0x7FFF1234`，但实际上这个地址可能映射到物理地址 `0x100000`。
   - 由 **操作系统和 MMU 进行地址转换（页表映射）**。

**DMA（Direct Memory Access，直接存储器访问）** 是一种**不经过 CPU** 直接在**外设（如硬盘、网卡、显卡）和内存之间传输数据**的机制。这样可以**减少 CPU 负担，提高系统性能**。 DMA 控制器（DMAC）是管理**外设和内存之间数据传输**的硬件模块，它可以**绕过 CPU，直接传输数据，提高性能**，常用于**磁盘读写、网络传输、音视频处理等**。

 指令流水线的操作周期按各步操作的最 大时间来考虑，
对 于 n条指 令 来 说 ， 先算出第 一 条指 令 的执 行 时 间 ， 然后 算 出 剩 下 n - 1 条 指 令的 执 行 时间,然后求总和

原理：第一条指令需要完整经历各阶段，后续指令每个只需一个时钟周期 T。当第一条指令在流水线中逐步推进时，后续指令会依次进入流水线。由于流水线的设计目的是让多个指令在不同阶段同时执行，以提高指令的执行效率。

### 物理层（Physical Layer）

- **功能**：负责在物理介质上传输原始的比特流，包括定义电缆、光纤、无线等传输介质的物理特性，以及信号的编码、传输速率、传输模式（单工、半双工、全双工）等。
- **示例**：常见的物理层设备有网卡、网线、集线器、中继器等。例如，网线（如双绞线）就是物理层的传输介质，网卡则负责将计算机内部的数字信号转换为适合在网线上传输的电信号。

### 数据链路层（Data Link Layer）

- **功能**：将物理层接收到的比特流封装成帧，进行差错检测和纠正，同时负责介质访问控制，即决定哪个设备可以在何时使用物理介质进行数据传输。
- **示例**：数据链路层协议有以太网协议、PPP（Point-to-Point Protocol）协议等。常见的设备有交换机，它根据 MAC 地址转发数据帧。

### 网络层（Network Layer）

- **功能**：负责将数据帧封装成数据包，进行逻辑地址（如 IP 地址）的寻址和路由选择，决定数据从源节点到目的节点的最佳路径。
- **示例**：网络层的主要协议是IP（Internet Protocol）协议，路由器是网络层的典型设备，它根据 IP 地址进行数据包的转发。

### 传输层（Transport Layer）

- **功能**：提供端到端的可靠通信，确保数据在传输过程中的完整性和顺序性。它可以分为面向连接的传输（如 TCP）和无连接的传输（如 UDP）。
- **示例**：TCP（Transmission Control Protocol）协议提供可靠的、面向连接的传输服务，常用于对数据准确性要求较高的应用，如网页浏览、电子邮件等；UDP（User Datagram Protocol）协议提供无连接的、不可靠的传输服务，常用于对实时性要求较高的应用，如视频会议、在线游戏等。

### 会话层（Session Layer）

- **功能**：负责建立、维护和管理不同主机之间的会话连接，包括会话的建立、拆除和同步，以及对会话进行管理和控制。
- **示例**：在远程登录（如 Telnet）和文件传输（如 FTP）等应用中，会话层负责建立和管理用户与服务器之间的会话。

### 表示层（Presentation Layer）

- **功能**：主要负责数据的表示和转换，包括数据的加密、解密、压缩、解压缩以及不同格式之间的转换，确保不同系统之间能够正确理解和处理数据。
- **示例**：在网页浏览中，浏览器会将服务器发送的 HTML、CSS、JavaScript 等数据进行解析和渲染，这其中就涉及到表示层的数据转换和处理。

### 应用层（Application Layer）

- **功能**：为用户提供应用程序接口，直接面向用户的应用程序，如电子邮件、文件传输、网页浏览等。
- **示例**：常见的应用层协议有 HTTP（Hypertext Transfer Protocol）、SMTP（Simple Mail Transfer Protocol）、FTP（File Transfer Protocol）DNS 等。
